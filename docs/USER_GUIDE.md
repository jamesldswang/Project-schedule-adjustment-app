# 操作手冊與會議對照指南 (User Guide)

本指南說明如何使用「時程對照台」建立專案基準、設定任務工期、切換視覺圖表、啟用雲端同步，以及在遭遇需求變更或時程延遲時保留完整版控證據。

---

## 一、建立新專案與初始版號

1. 點擊工作列左側的 **`+ New 專案`** 按鈕。
2. 填寫專案基本資訊：
   - **專案編號**：系統自動帶入遞增編號（如 `J261114`），亦可自行修改。
   - **專案名稱**、**負責人**與 **Kickoff 起始日**。
   - **初始版控版號**：預設為 `v1.0.0`，可點擊快速按鈕切換 `v1.0.0` / `v1.0` / `v0.1.0` 或自訂格式。
   - **三大階段名稱**：自訂 `001` / `002` / `003` 各階段名稱。
3. 勾選「自動帶入標準階段範本任務與起訖里程碑」即可快速產生基礎架構，按下建立後系統會自動建立第一筆不可變的初始基準快照。

---

## 二、設定 Tasks 與 Duration 工期

切換至 **`Tasks & 工期`** 頁籤：

1. **新增項目**：點擊「新增任務 / 里程碑」，選擇類型為 `工作任務 (Task)` 或 `里程碑 (Milestone)`，指定所屬階段、開始日期與工期天數。
2. **調整工期**：
   - 可直接在表格中修改「開始日期」、「結束日期」或「工期天數」，系統會即時雙向換算。
   - 使用工期欄位的 **`-` / `+`** 按鈕可快速以 1 天為單位增減。
3. **前置相依連動**：
   - 在「前置相依」欄位指定前置任務後，若勾選上方「調整工期時自動順延相依後續任務」，調整上游工期時下游項目將自動往後推算。
4. **設定里程碑交付物標籤**：
   - 針對 `Milestone` 項目，點擊名稱下方的「+ 設定 Milestone 交付物標籤」（多筆請以逗號 `,` 分隔），該標籤會直接顯示於 Milestone 圖節點上方。

---

## 三、檢視 Milestone 圖與切換 Gantt Chart

- **Milestone 圖**：
  - 顯示專案頂部「狀態快照」、水平主時程節點、`001 / 002 / 003` 階段區間條與細項清單，以及底部「查核點時程與溝通紀錄」。
  - 點擊任一里程碑圓環節點，可於下方展開該節點在各歷史版次的日期變化與對應修正原因。
  - 可隨時點擊右側待確認備註區的「編輯」更新待追蹤事項，或於底部「+ 新增查核點紀錄」補充客戶/團隊溝通備忘。
- **Gantt Chart 甘特圖**：
  - 點擊頂部或視圖內的 **`Gantt Chart`** 按鈕即可切換至甘特圖。
  - 右上角提供 **日視圖 / 週視圖 / 月視圖** 縮放切換。
  - 點擊甘特圖中的任一任務條或里程碑菱形，上方會開啟快速檢視器，可直接用 `-1d / +1d / +7d` 位移起日或微調工期，同時列出該項目在各版次間的歷史變動原因。

## 四、記錄修訂原因與新舊計畫對照（會議應答流程）

### 1. 當變數發生並調整完時程後，儲存新修訂版
1. 在 `Tasks & 工期` 或 `Gantt Chart` 完成日期與工期調整後，上方對照列會提示「目前有未存檔變更」。
2. 點擊右上角 **`儲存修訂版`** 按鈕。
3. 系統會自動比對現行計畫與前一版的差異明細，接著填寫：
   - **版本編號**：可使用 `+修訂` / `+次版` / `+主版` 快速遞增。
   - **變更歸因分類**：如 `客戶延遲`、`需求變更`、`技術調整`、`測試複驗`。
   - **修訂版標題** 與 **詳細修正原因與依據**（建議寫明會議日期、決定事項或外部等待文件名稱）。
4. 確認存檔後，該版次將永久保留為歷史快照，供日後對照。

### 2. 在圖表上勾選舊計畫進行視覺對照
1. 在 `Milestone 圖` 或 `Gantt Chart` 上方的 **「勾選歷史版本與現行計畫對照」** 控制列中，勾選欲比較的一個或多個歷史版本（例如同時勾選 `v1.0` 與 `v1.1`）。
2. 圖表會即時疊加顯示：
   - **Milestone 圖**：顯示舊版原訂里程碑節點、虛線位移箭頭與偏移天數，並於各階段條下方顯示原訂區間對照。
   - **Gantt Chart**：於現行任務條下方顯示舊版斜紋基準條與延後/工期增減天數；可勾選「只看有差異之任務」快速聚焦變動項目。
3. 點擊右側 **`查看已勾選修正原因`** 可一次展開所勾選版次的完整事由與影響摘要。

### 3. 產出完整稽核表與簡報報告
1. 切換至 **`修訂對照表`** 頁籤。
2. 於上方選擇任意 **基準舊版** 與 **對照新版（或現行計畫）**。
3. 檢視整體完工日位移天數、歷次修訂事由列表與逐項任務變化表。
4. 點擊 **`匯出對照報告 (.md)`** 下載結構化會議紀錄檔，或點擊 **`列印簡報對照頁`** 直接列印 / 另存為 PDF。

## 五、Google 帳號登入與雲端跨裝置同步

1. **未登入狀態**：所有專案與修訂紀錄預設儲存於當前裝置的瀏覽器 `localStorage`，可隨時單機編輯與展示。
2. **啟用雲端同步**：點擊專案控制列上的 **`Google 登入同步`**，透過彈出視窗完成 Google 帳號驗證。
   - 首次登入時，若帳號尚未建立雲端專案，系統會自動將預設的 **`J261113 · 月球寧靜海熔岩管基地專案`** 寫入 Cloud Firestore。
   - 登入後的所有任務工期異動、查核點、補充備註、新建專案與修訂版快照皆會自動同步保存，跨瀏覽器或跨裝置登入即可接續管理。
   - 若需再次加入範本專案，可點擊專案列上的 **`匯入範例`**；操作完畢可點擊 **`登出`** 結束雲端連線。
